# Greece source candidates

Skill: author-source-pack-rules v1.0.1

Greece has a bounded discovery register of 56 official-source candidates across legal publication, free movement/residence, visa and mission practice, civil status, public access and procedure, courts, complaints, privacy, legal aid and selected local practice. The candidates are not accepted sources. No source bytes were saved locally, and no Greek retrieval or conversion rule is implemented.

The official Gazette route is promising for retrieving known issue PDFs, but no machine API contract, complete amendment discovery method or conversion replay has been established. The National Printing House search-site terms contain a material copying/conversion restriction whose application to direct API PDFs and internal monitoring is unresolved. The codification portal is still described as being in its final implementation stage.
