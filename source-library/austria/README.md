# Austria national-source candidates

This is the first country register in the EEA-plus-Switzerland expansion. It currently contains 31 official discovery candidates and a proposed-route sustainability assessment, not an active retrieval pack. The register covers the NAG free-movement sections and authority/venue rules, Swiss eligibility, public-information access, general remedies, sample administrative-court decisions across three court levels, and central BMEIA visa and residence guidance. No source is accepted, and no Austria action is exposed by the monitor MCP yet. Since no Austria source rule is implemented, the assessment records proposed-route evidence and missing implementation work without assigning rule verdicts.
