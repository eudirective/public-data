# Austria national-source candidates

This is the first country register in the EEA-plus-Switzerland expansion. It currently contains 36 official discovery candidates and a proposed-route sustainability assessment, not an active retrieval pack. The register covers the NAG free-movement sections and authority/venue rules, Swiss eligibility, NAG-DV Annex E/F PDF records, IFG public-information access and DSB oversight, general remedies, sample administrative-court decisions across three court levels, central BMEIA visa and residence guidance, oesterreich.gv.at visa-application guidance, and BMEIA's representation directory. Official RIS search surfaces for the LVwG, BVwG, and VwGH are documented as discovery routes, with the LVwG selected-decision limitation explicit. No source is accepted, and no Austria action is exposed by the monitor MCP yet. Since no Austria source rule is implemented, the assessment records proposed-route evidence and missing implementation work without assigning rule verdicts. Mission-specific pages remain an open, applicant-location-dependent search.
