# Liechtenstein national-source review

**Review date:** 2026-10-25. **Status:** 3 accepted official references (2 local documents, 1 link-only reference); 1 duplicate lead dispositioned; 0 topics accepted; country review incomplete.

The accepted sources are the [Personenfreizügigkeitsgesetz (PFZG)](documents/legislation/li-personenfreizuegigkeitsgesetz-pfzg.md), LR 152.21; the [Personenfreizügigkeitsverordnung (PFZV)](documents/legislation/li-personenfreizuegigkeitsverordnung-pfzv.md), LR 152.211; and the [official Lilex consolidated-law search and version guidance](https://www.gesetze.li/konso/suche). Lilex's consolidations are informational and have no legal effect; signed State Law Gazette publication remains legally authentic. PFZG reflects Liechtenstein's special EEA solution and separate Swiss framework, not a legal-equivalence finding.
