# Belgium national-source candidates

This is the second alphabetical discovery installment in the 31-jurisdiction EEA-plus-Switzerland expansion. It reconciles the prior public-mirror Belgium inventory with the expanded review and records 39 distinct official candidates. Two previously retrieved documents remain converted review candidates; none is accepted, and no Belgian retrieval/conversion rule or active pack action is implemented.

The candidates cover the Immigration Act and implementing decree, official forms and indexes, EU-family residence guidance, a distinct mobile-Belgian route, D-visa instructions, national consular routing and mission examples, administrative procedure, access to records at federal and regional levels, complaint and review channels, data protection, private international law, adoption guidance, and a selected court-material lead. The review surfaced concrete access and maintenance constraints, including Justel's extensive version history, Immigration Office pages that require JavaScript or return human-verification challenges, an Annex 19ter link whose payload returned an HTML error, a versioned Walloon legislation route that can display an obsolete edition, and a court site that returned HTTP 403.
