# France national source references

**Review updated 2026-10-30.** The France library has 26 accepted local documents: 19 retained official source texts (8 Service Public/DILA guidance or procedure records, 9 DILA LEGI statutory texts, 1 CNIL text, and 1 Conseil d’État source guide) plus 7 project-authored maintained summaries.

**A URL is a locator, not a source document.** The source list and acceptance register may retain official URLs for provenance and navigation. Those URLs are not accepted source documents and do not count toward the accepted-source count. Accepted text is retained under `documents/`; the 7 maintained summaries are clearly recorded as authored summaries, not verbatim official legal text.

Five new bounded statutory text files cover selected provisions from the Code du travail, Code de la sécurité sociale, Code de l’éducation, Code de la santé publique, and Code de procédure civile. Their article scopes, SHA-256 values, verification findings, and limits are listed in the [source list](references/source-list.md). The Legalize France retrieval and conversion rules are recorded in [legalize-fr-conversion-rules.md](references/legalize-fr-conversion-rules.md). No whole Legalize code file was accepted. Four of the five candidate article groups matched current Légifrance wording; the Code du travail and social-security extracts include corrections/additions from official DILA LEGI XML. Stale neighboring content was excluded.

## Coverage limits

The source pack remains incomplete. The five new statutory files contain only the listed articles or sections, not full codes. The CESEDA legislative and regulatory Book II URLs remain locators for official text; the local CESEDA files are maintained summaries rather than verbatim statutory copies. The other 74 files in the pinned Legalize France repository were not issue-triaged, and their absence is not a finding that all are relevant or that specific provisions are missing.

The Service Public family-card snapshot still reflects the publisher's 2024-02-02 verification date and carries a freshness caveat. Compatibility of the latest listed 2018 DILA DTD with current LEGI data remains open. Recheck current official versions before date-sensitive use.

Legacy candidates, raw captures, and retrieval/conversion history are preserved in the Monitor's indexed local-only archive rather than treated as accepted source documents. The 18 legacy candidate files were reviewed; historical retrieval errors remain archived and were not replayed. France has no registered Source Monitor pack action. No visa or ANEF application was submitted, and no applicant data was accessed.
