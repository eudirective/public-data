## Retrieval and conversion

Rules are recorded in [source-rules.json](references/source-rules.json). For ordinary research, a human-reviewed official link is enough; record publisher, title or stable ID, language, review date, displayed edition/cutoff, relevant passage and visible caveats. Local capture, hashes, conversion and replay are optional and apply only when retaining a copy or operating a recurring updater. Do not bypass access challenges. If a stored capture changes, review that copy again; the external link may still be used within its verified scope.

When storing a local conversion, use source-specific extraction and review only the passages, pages or attachments relied on. Keep original OCR/PDF files in the Monitor local-only archive when a reproducible local copy is useful; do not require full-document OCR acceptance to cite an official source. The retained scripts describe the earlier conversion workflow. Their raw and derived inputs are no longer in this checkout, so replay is unsupported here; past replay results remain historical evidence only.

The inventory consistency check remains available:

```sh
python3 source-library/cyprus/scripts/validate_inventory.py
```

The legacy OCR/PDF replay and candidate-page verification commands are unsupported in this checkout because their raw and derived inputs are held only in the Monitor local-only archive. Their absence is not a passed replay check. Replay can be assessed separately if a future task stages those archived bytes in the standard temporary workspace.
