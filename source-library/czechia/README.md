The principal legislation publisher is [e-Sbírka](https://e-sbirka.gov.cz/), the Czech official electronic Collection of Laws and International Treaties. REST API access requires an issued key, so the pack does not depend on it. e-Sbírka says individual legal acts can be obtained as open data, open text, or generated PDF ([official announcement](https://e-sbirka.gov.cz/aktuality/20151)) and documents [stable URLs and ELI](https://e-sbirka.gov.cz/pristup-pres-stale-url-a-eli). The script derives `/sb/{year}/{number}/{yyyy-mm-dd}.pdf` from each official stable act record using the UTC check date. It requires an official PDF content type and signature, checks the act citation in extracted text, and stores the date-bound URL with the review candidate. This is a keyless public download route, not an API. The live route could not be reached from the current workspace during repair, so the rule remains pending a successful live retrieval. e-Sbírka describes consolidated text as informative; the requested date identifies a consolidation snapshot and does not establish legal force or applicability. The [National Open Data Catalog's e-Sbírka datasets](https://data.gov.cz/dataset?iri=https%3A%2F%2Fdata.gov.cz%2Fzdroj%2Fdatov%C3%A9-sady%2F00007064%2F1296131372) are a possible later bulk route; its publisher warns that identifiers and structures may change through 15 January 2027.

The local monitor now has a `czechia` pack action for official guidance retrieval, date-bound e-Sbírka PDF retrieval, conversion, replay verification, and reviewed acknowledgement. The separate hosted connector still has no Czechia pack ID.

Run `node scripts/sync-czechia.mjs --check|--sync|--verify|--reconvert|--ack <source-id>` from this directory. The UTC check date is sent as the consolidation date for the legal PDF route. `--sync` saves original HTML/PDF bytes and review Markdown under `work/`; `--verify` replays conversions offline; `--reconvert` refreshes an unaccepted candidate from hash-verified saved bytes without fetching or promoting it. The local MCP action uses the same script from the plugin bundle.
